Request flow — employee asks a question

1

Browser → Supabase Auth: sign-in returns a session JWT.

2

Browser → FastAPI: POST /chat/ask with Bearer JWT.

3

FastAPI: verify JWT via JWKS, resolve users row, enforce role/status.

4

Redis: context-aware cache lookup (question + conversation).

5

LangGraph: classify intent → retrieve Pinecone + Cohere rerank → (Tavily if external) → grade/merge.

6

Groq: synthesize grounded answer with citations.

7

Postgres: persist conversation + messages; cache the response.

8

Browser: render answer, sources, and follow-ups.
